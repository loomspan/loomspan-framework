## Detailed findings

### Pack construction and transport ownership

Paths in this subsection are relative to `../loomspan-extensions/`.

- `extensions/decisions/pom.xml:7` identifies independently versioned unpublished
  `ai.loomspan:loomspan-decisions:0.1.0-SNAPSHOT`. It depends on Framework
  `1.0.0-beta.10-SNAPSHOT`, Boot `4.2.0-RC2`, HttpClient and Jackson. Java baseline is 21.
- `extensions/decisions/src/main/java/ai/loomspan/decisions/autoconfigure/DecisionsAutoConfiguration.java:11`
  creates one executor and one transport bean with `destroyMethod="close"`.
  These are pack construction details, not supported bean replacement contracts.
- `extensions/decisions/src/main/java/ai/loomspan/decisions/internal/typesafe/TypeSafeExecutor.java:15`
  uses `@SkillExecutor(name="typesafe", config="typesafe")`, exact v1 invocation,
  prepares request bytes once and serializes the decoded native result to JSON text.
  The String return preserves JSON null/string across generic Java invocation.
- `TypeSafeTransport.java:39` owns one pooled HttpClient and deadline executor.
  Automatic Apache retries and redirects are disabled. Each request sets its own
  authorization, endpoint and timeouts. Settings are captured once per send.
- `TypeSafeTransport.java:77` implements up to three attempts. HTTP status is
  classified before successful decoding. Error capture retains a bounded body;
  malformed error bodies do not prevent retry classification. Successful empty or
  malformed JSON fails outside the IO retry catch.
- `TypeSafeTransport.java:122` caps the per-attempt total budget with live remaining
  Framework time. A 25ms watchdog polls live cancellation, interruption, closure
  and deadline and cancels the Apache request; progressing bytes do not reset it.
- `TypeSafeTransport.java:244` cooperates during retry waits, restores interruption
  on `InterruptedException`, and checks cancellation/deadline before another send.
- `TypeSafeTransport.java:273` contains diagnostic target access, data preparation
  and recording RuntimeExceptions around diagnostic-only work. Business request
  construction and result serialization remain outside that block.
- `TransportPolicy.java:8` sets 60s total, 30s inactivity, 5s pool acquire, 10s
  connect, 250/500ms backoff and 5s Retry-After cap. These are fixed pack policy.
- `TypeSafeTransport.close()` closes the client, stops the watchdog and awaits its
  termination. The shared transport has application rather than generation lifetime.
