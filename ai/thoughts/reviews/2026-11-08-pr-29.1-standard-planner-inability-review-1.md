# PR 29.1 independent review 1

## Code Review Findings

### [P2] Preserve escaped reason code units in canonical failure recording

- **Location** `src/main/java/ai/loomspan/internal/runtime/trace/NdjsonTraceRecordWriter.java` and `DefaultExecutionTraceHandle.java` in the same package.
- **Evidence** The control parser decodes JSON escapes to the exact Java string. The candidate then serialized the canonical record through a character writer that could not encode an isolated UTF-16 surrogate as UTF-8. The four-driver test had ordinary Unicode, and the existing trace chunk fix kept valid surrogate pairs together. Neither covered a decoded isolated surrogate.
- **Trigger** The OpenAI adapter returns a bound control with a nonblank reason ending in an escaped `\uD800`. The pinned mapper accepts the string, and the actual adapter test observes the exact exception reason.
- **Impact** The exception reached the caller, but failure recording emitted only the chunk envelope. The canonical reader returned no failure payload, so the reason and signal diagnostic were unavailable through that record.
- **Correction** Write NDJSON with Jackson's UTF-8 generator. Use the same encoding for serialized structured chunk content, signal diagnostics, and failed-call feedback. The JSON representation preserves isolated code units as escapes. The decoded fields and existing chunk and diagnostic limits remain the same.

### [P3] Correct the supported Java type count in the bundled reference

- **Location** `agent-skills/loomspan-docs/references/java-api/README.md:56` and `agent-skills/loomspan-docs/references/java-api/compatibility-and-boundaries.md:12`.
- **Evidence** The changed lists add `PlannerInabilityException`, but four count statements still said twenty-five. The repository README and executable allowlist count twenty-six.
- **Trigger** A consumer follows the Java API knowledge-set index or its compatibility reference to establish the supported surface.
- **Impact** The package boundary guidance contradicts its own type list and the executable contract.
- **Correction** Update the four count statements to twenty-six.
