## Findings Resolved in This Context

### [P1] Bound alias expansion before traversing and freezing YAML containers

- **Location:** `src/main/java/ai/loomspan/internal/serialization/YamlValues.java:32`, `src/main/java/ai/loomspan/internal/util/ImmutableContainers.java:19`.
- **Evidence:** The decoder allowed unrestricted collection aliases. Its cycle walk revisited each shared node on every path, and the shared immutable copier allocated a separate subtree on every occurrence. Jackson manifest conversion and Boot flattening could also expand the resulting graph after decoding.
- **Trigger:** A 336-character YAML graph with fourteen levels, each containing two references to its predecessor, already expanded fifteen distinct source containers into tens of thousands of copied containers. A safe Java probe verified `rawSharesChildren=true` and `immutableSharesChildren=false` before correction. Extending the same small graph to roughly thirty levels creates billions of visits/copies; publication and supplied manifest inputs reach this path without application invocation.
- **Impact:** Small authored inputs can consume excessive CPU and heap during validation/preparation or startup; the existing execution-configuration character limit does not bound alias expansion.
- **Correction:** The shared YAML walk memoizes completed identities while preserving active-path cycle rejection and computes logical expansion with a 1,000,000-value resource limit before downstream tree processing. The existing immutable copier memoizes completed frozen containers, retains scalar leaves, and rejects recursion. It does not classify, modify, interpolate, or redact data. Valid alias contents remain immutable and shared safely.
- **Verification:** `ExecutorConfigurationTests.aliasedConfigurationDoesNotExpandIntoAnExponentialContainerTree` verifies sharing and immutability through the actual publication parser; `aliasExpansionIsBoundedBeforeDownstreamTreeProcessing` verifies rejection of a tiny twenty-four-level graph. The same probe now reports `immutableSharesChildren=true`. Existing recursive-alias, manifest fidelity, startup fidelity, API defensive-copy and shared Java invocation tests pass.
