# PR 27.2 independent namespace publication — review 1

## Code Review Findings

The initial independent review found three actionable issues. All were corrected
in this context; no actionable issue remains after the internal re-review.

### [P2] Keep root namespace parsing inside the facade failure boundary

- **Location:** `src/main/java/ai/loomspan/internal/skillapi/DefaultSkillTemplate.java:117,143` in the reviewed candidate.
- **Evidence:** Namespace selection called `SkillIdentity.parse` before the existing runtime-exception wrapper. The pristine baseline returned `SkillException` for unknown/malformed root names; the candidate leaked `IllegalArgumentException` for malformed, unqualified or oversized references.
- **Trigger:** An invocation, validation or handoff supplies an invalid qualified root reference, including an obsolete implementation target such as `bean#javaSkill`.
- **Impact:** Applications following the documented facade exception boundary could miss the failure. The candidate-only failing method in the full-suite comparison demonstrated this change. A new regression test reproduced it independently before the fix.
- **Correction:** A private namespace-selection helper wraps parser failures as `SkillException` with their original cause. It introduces no alias, repair, fallback, public API, or alternate identity syntax. Canonical missing namespaces already fail with `SkillReloadException`, which extends `SkillException`; those were not a separate defect.

### [P2] Remove the remaining active-configuration inheritance guidance

- **Location:** `agent-skills/loomspan-docs/references/skill-authoring/model-selection-and-connections.md:49`.
- **Evidence:** The routed connection guide still said skill-only updates copy active generation settings, even though this change deliberately removes those overloads and requires complete namespace configuration. The skill-authoring coverage table also still listed active-registry integration as future PR 27.2 work.
- **Trigger:** An author loads the model-selection guide or coverage index to plan a replacement.
- **Impact:** The guide recommends an unavailable workflow and contradicts default-reset behavior required by the ticket.
- **Correction:** State required complete configuration, built-in scalar defaults and no model/connection/previous-setting inheritance; update the coverage row to distinguish implemented management from downstream execution work.

### [P3] Validate the same visibility that the example prepares

- **Location:** `agent-skills/loomspan-docs/references/java-api/skill-reload.md:19`.
- **Evidence:** The example validated default Private visibility and then prepared explicit Public visibility.
- **Trigger:** A valid staged Public cycle has an external return edge into the candidate namespace.
- **Impact:** The example rejects the Private draft and never attempts a valid Public publication. `SkillDependencyValidatorTest.transitiveReturnUsesCandidateDeclarationsContractsAndVisibility` establishes the distinction.
- **Correction:** Pass `NamespaceVisibility.PUBLIC` to both validation and preparation in that example.

### Ownership and synchronization audit

`generationMonitor`. Expensive parse/schema/provider work is outside that monitor
and lifecycle admission synchronization. Candidate state is guarded only while
checking/transferring ownership; physical close and retirement callbacks occur
outside registry/lifecycle locks. Existing lease and physical-work retention paths
remain in effect, with listener failure isolation and no durable delivery promise.

Preparation reads only immutable definitions/constraints, canonical identities,
visibility, input contracts, schemas, kinds and diagnostic metadata from captured
external generations. It does not read their clients or runtime configuration,
invoke REST/application methods, or acquire provider resources. Runtime retirement
does not mutate those metadata objects. No executable lease is required for those
audited reads; no dependency owner is retained through unrelated provider creation
or candidate staging. Candidate resources remain independent until publication.
