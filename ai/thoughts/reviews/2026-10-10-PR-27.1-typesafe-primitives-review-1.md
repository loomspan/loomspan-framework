The lifecycle cancellation handle aborts the actual request, not merely a worker future; registration checks cancellation/fence state, owning-work completion retains generation resources, and existing ancestry write gates protect accounting and trace writes. Shared retry decisions apply the native 529 mapping without changing chat status classification.

Native exact/unavailable usage is recorded before extraction failure; HTTP error bodies do not enter response accounting. Error-only capture is bounded with truthful metadata and stops draining oversized entities.
