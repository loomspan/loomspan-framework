## Findings Resolved in This Context

### [P2] Preserve YAML document association through empty sequences and null spellings

- **Location:** `src/main/java/ai/loomspan/internal/autoconfigure/ExecutorYamlPropertySourceLoader.java:24`
- **Evidence:** The original raw `YAMLMapper.readerFor(Object.class).readValues` treated a leading `[]` as the iterator envelope rather than one YAML document, losing the following document. Its JSON-style scalar decoding treated an unquoted root `~` as text while Boot discarded it as null. The delegated and raw document counts therefore differed.
- **Trigger:** A normal configuration stream beginning with `---\n[]\n---\n...` or `---\n~\n---\n...`; no executor configuration was necessary to trigger the globally installed loader.
- **Impact:** Applications whose YAML the ordinary Boot loader accepted could fail startup with `YAML document association mismatch`.
- **Correction:** Shared raw `YamlValues` decoding preserves YAML documents and Core null semantics before filtering documents as Boot does. The ordinary Boot loader still owns non-executor properties and their origins. Real Config Data tests cover leading empty sequence, tilde/null and quoted empty-string documents, profiles/imports and ordinary tagged timestamps.
- **Verification:** Direct pre-fix Java probes compared the production and ordinary Boot loaders and reproduced both mismatches. `ExecutorConfigurationStartupTests#leadingNullAndSequenceDocumentsDoNotBreakAssociation` protects the corrected path.

### [P2] Keep YAML null/container semantics and raw executor values at all ingress boundaries

- **Location:** `src/main/java/ai/loomspan/internal/skill/YamlSkillCatalog.java:404`
- **Evidence:** Jackson's untyped YAML decode turned unquoted `~` into the literal string `"~"` and aliased containers into anchor-name strings. In addition, the original manifest ingestion passed executor config through a JSON tree and typed conversion before the later container copy.
- **Trigger:** Executor-owned maps/lists containing a YAML null written `~`, or a reference to a previously anchored container.
- **Impact:** Executor input data could change meaning before becoming the advertised immutable structural declaration/configuration value.
- **Correction:** Startup, publication and manifests share the same safe raw YAML ingress. Manifest form validation sees only config presence/type; the actual config map stays outside JSON conversion and enters the existing container copier directly. Quoted tilde remains text. Cyclic aliases reject before container copying; ordinary repeated aliases retain their values. Explicit timestamps remain textual in raw value decoding, matching the prior Jackson ingress, while ordinary Spring timestamp values continue through Boot.
- **Verification:** Startup/publication equivalence and manifest regressions assert map/null values, quoted text and recursive-container rejection. Existing exact scalar/key, copy, TypeSafe and model tests remain meaningful.

Also removed an accidentally duplicated paragraph in the mental-model guidance and updated the authoring topic, internal architecture classification and governing implementation choice to reflect the corrected shared ingress. These edits create no application-facing API or resolver.
