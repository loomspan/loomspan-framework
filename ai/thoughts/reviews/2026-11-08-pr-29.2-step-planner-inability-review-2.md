## Code Review Findings

### [P3] Scope output binding guidance to successful synthesis

- **Location** — `StepLoopMissionExecutionEngine.java:936`.
- **Evidence** — The final action prompt allows `CANNOT_COMPLETE`. When output bindings leave model-owned fields, the engine then appends `OutputBindingProjection.guidance()`, which ends with “Return only the model-owned output contribution.” The same appended guidance also appears in correction turns.
- **Trigger** — A step mission reaches final synthesis with a partial output binding and the available results cannot fulfill the objective.
- **Impact** — Framework instructions conflict about what the model may return in a supported synthesis context. The prompt can steer it away from the accepted failure declaration even though the runtime supports it.
- **Recommendation** — Apply the binding guidance to the `finalResponse` payload of `FINAL_RESPONSE` and keep the existing declaration instructions applicable in that same prompt.
