## Risk Assessment and protected boundaries

1. A fake returning prose or runtime `planId` fails before the security/concurrency
   assertion it intended to exercise. Fix model contributions without changing
   authoritative runtime ownership, plan admission, deadlines or quotas.
2. A direct advisor test without call-local repair/raw output fails correctly. Fix
   its invocation lifecycle; do not add a production context fallback.
3. Standard local openness/optional semantics are broader than strict OpenAI native
   output. Keep both local semantic proof and explicit provider incompatibility
   proof. Never reshape canonical schemas into all-required/closed contracts.
4. Known B04 can prevent Gemini plan serialization before response status handling.
   Record the exact blocked consumer; retain other Gemini status paths and complete
   opt-in correctness assertions. A passing characterization is failure-timing proof.
5. Aggregate green with skips can hide lost fidelity. Classify exact test and
   parameter identities and retain all original assertions. Fourteen original
   B01–B05 invocations are distinct from two pre-existing diagnostics and any
   explicitly accounted integrated B04 parameter.
6. Full checks share generated/report files. Serialize Maven and npm mutations;
   parallelize only independent work. Do not leave opt-in failing Surefire reports
   as the final default-verification receipt.

Protected contracts: the closed application API allowlist, named configuration and
manifest semantics, exact Console version matching/current writer-reader coherence,
canonical content, authorization, invocation isolation and runtime ownership.
There is no supported SPI. Internal fake constructors/advisor implementations may
change atomically without shims. Diagnostic assertions use current canonical codes,
paths, ordering and exact content. Preserve only existing journal field-name rules;
never apply them to canonical traces/prompts/invoke results/Console.
