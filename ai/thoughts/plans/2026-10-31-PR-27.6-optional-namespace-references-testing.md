## Risk Assessment

| Risk | Required evidence |
| --- | --- |
| Wrong owner or ambient binding changes shorthand | Identical authored bytes under several owners; root local remains default inside non-default active work. |
| One raw/typed position remains strict or local | Exercise allowed child, forwarding, input producer, output producer and evidence separately and in a mixed composition. |
| Availability-based fallback | Owner lacks target while default and Public foreign namespaces contain same local name; validation/preparation/root still fail in resolved owner. |
| Lost canonical equality | Local/qualified duplicate children fail; mixed binding/forwarding spellings match same direct child. |
| Relaxed internal/model/catalog parsing | Existing strict identity/generation/catalog and model plan/step tests still reject local input. |
| Data or position rewriting | Exact source bytes/prose/original evidence survive; later-token syntax/reference columns match authored text despite earlier qualification. |
| Access/lifecycle weakening | Same-owner Private success, explicit Public foreign success, Private foreign failure, RBAC/undeclared-call failures and retained handoff behavior. |
| Unintended API/wire growth | Supported-surface architecture and existing canonical REST/observation corpus checks, no new protocol fields/markers. |

Protected contracts: existing qualified Application API calls, strict catalog
lookup, manifest declaration grammar/ownership, sole REST SPI identities,
configuration shapes, current canonical Java/Go observations, and captured access
and lifecycle behavior. Obsolete local-input rejection is deliberately removed
only at authored/root boundaries under the ticket's Pipeline notes. No test
should require old and new behavior simultaneously at those boundaries.

## Tests to Add/Update

### 1. Boundary resolution and strict canonical parsing

- **Type/location:** Unit, existing `src/test/java/ai/loomspan/internal/core/SkillIdentityTest.java`.
- **Proves:** Boundary resolution constructs owner-qualified identities; explicit
  namespaces normalize only namespace case; local case remains exact. Existing
  `SkillIdentity.parse("child")` and malformed qualified forms still fail.
- **Inputs:** Local `Search`, explicit `Shared-Search`, whitespace/empty/null,
  `-child`, `sales-`, `sales-child-extra`, slash/colon, non-ASCII, namespaces 32/33,
  and total 64/65 after owner supplied. `default` permits 56 local characters;
  owner length 32 permits 31.
- **Mocks:** None. **Surface:** Internal canonical invariant supporting
  Application API/manifest input. **Compatibility:** Preserve strict parser and
  existing limits; new helper is boundary-only.

### 2. Equivalent root targets across all eight operations

- **Type/location:** Facade with real manager, `internal/skill/SkillReachableAdmissionTest`;
  malformed wrapping in `internal/skillapi/DefaultSkillTemplateTest`.
- **Proves:** Both Map/Object validation, ordinary invocation, observer invocation
  and handoff resolve `root` and `default-root` to the same metadata/generation.
  Observer identities remain canonical. Explicit foreign references stay foreign.
- **Fixtures:** Publish `default-root` and distinguishable `sales-root`; mocked
  router asserts `ExecutionBindingScope` canonical entry and target. Reuse
  lifecycle cleanup helpers, Map plus Object/DTO inputs and observer counters.
- **Negative cases:** Missing `default-root` with `sales-root` Public must fail
  across all operations without router/observer calls. Wrong local-name case and
  identities oversized only after default qualification fail. Keep genuinely
  malformed qualified-input wrapping and null input ordering tests.
- **Captured/ambient case:** While executing `sales-root`, validate and prepare a
  handoff for local `leaf` with distinguishable default/sales leaves; assert
  captured default generation, then invoke after outer work ends. Nested actual
  root execution remains rejected. Admit local default handoff, replace/remove
  default, and prove it retains its original canonical captured target/id.
- **Mocks:** Router only; manager/capture/lifecycle real. **Surface:** Application
  API. **Compatibility:** Qualified calls and error/lifecycle boundaries preserved;
  local syntax expansion deliberate.

### 3. Every authored reference family with local/qualified/mixed spelling

- **Type/location:** Unit, `internal/skill/NamespaceIdentityFoundationTest` and
  existing catalog tests where structure rules are already isolated.
- **Proves:** Prepared allowed constraints, output-from, input producers, output
  producers and evidence leaves are qualified for owner. Forwarding and producer
  comparisons accept local allowed child plus explicit owner producer and reverse.
- **Fixtures:** Existing configured model; parent with local producer/consumer;
  use independent forwarding versus output-schema/output-binding manifests to
  respect existing mutual exclusions. Test all-local, all-qualified and mixed
  forms. Load the same literal local document under `default`, `sales`, `other`;
  explicit `shared-child` remains shared in all. Inspect strict records and
  canonical definitions, not rewritten source strings.
- **Duplicates:** `[child, sales-child]` under sales and namespace-case variants
  reject; `child` and `Child` remain distinct. Missing targets are checked in
  validation/preparation integration below, not inferred from catalog load alone.
- **Grammar/limits:** Remove local `child` from old malformed matrix; retain
  invalid separators/whitespace/extra hyphens and namespace overflow. For each
  family cover owner-32/local-31 success and local-32 failure at total 65,
  independent of whether target is offered. Field/source diagnostics retained.
- **Mocks:** None for catalog, fixed Java registrations only where existing
  manager fixtures need them. **Surface:** Manifest contract/internal compilation.
  **Compatibility:** Qualified documents preserved; local rejection intentionally
  removed; strict semantic constructors remain strict.

### 4. Contextual evidence with original expression columns

- **Type/location:** Unit, `internal/runtime/evidence/EvidenceExpressionParserTest`
  (or AdditionalTest), `internal/skill/YamlSkillEvidenceExpressionCatalogAdditionalTest`.
- **Proves:** Owner-aware parse of `first and (second or shared-third)` produces

- **Fixtures:** Expressions with leading whitespace, earlier short local token

- **Mocks:** None. **Surface:** Manifest contract and ephemeral diagnostics.
  **Compatibility:** Grammar, truth sets and source positions preserved.
