## Implemented behavior

- `SkillGeneration` owns separate immutable callable/definition and fixed-executor indexes plus its own namespace configuration. Startup initializes callable/executor namespace union. Replacement and explicit recreation reuse assigned registrations with newly supplied configuration through the existing owner/retirement machinery.
- `SkillDependencyValidator` owns shared canonical identity/namespace access resolution for callable and executor references. Its role-specific checks validate callable contracts or exact executor dot-path map selection. Complete target metadata overlays captured foreign metadata during preparation; no foreign binding is stored in the resulting caller generation.
- Capture walks only root-reachable callable edges and selects executor namespaces without walking their unrelated declarations. One selected map/lease covers both roles. Validation outside the registry monitor returns immutable per-leaf executor bindings in a new admission snapshot using those same selected generations and owner lease.
- `DefaultSkillTemplate` passes the admitted snapshot into invocation/handoff. The single Java branch resolves input references, opens existing scoped authentication and bounded mission work, then either invokes the callable method or constructs the five-field executor invocation from the admitted registration/configuration and executing YAML declaration.
- Executor YAML has execution kind `JAVA` and retains its definition/source/configuration. Framework diagnostic source lookup uses declaration ownership; executor YAML currently has YAML source provenance in the existing diagnostic shape. No new diagnostic fields or compatibility reader were introduced.
- Deleted REST handler/invocation API, REST execution kind, handler discovery/wiring and obsolete execution support. Removed `CapabilityKind`: inspection found only one-to-one translation to `SkillKind`, so there is no distinct behavior justifying a second classification. Supported API has 25 top-level types and no interface SPI.
- Migrated REST-backed orchestration, binding, namespace and public-surface fixtures to actual annotated executor beans while retaining their behavior assertions. Updated live README, repository guidance, architecture/maintainer guidance and routed `loomspan-docs` topics; deleted obsolete REST usage topic.
