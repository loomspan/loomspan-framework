## Impacted Areas and Risks

- `TraceRecords.tsx`: selecting physical raw envelopes instead of logical payloads would lose chunked attachments; partial bytes or range-local UTF-8 decoding could corrupt metadata.
- Evidence source/scope changes: cached or pending detail must not expose a previous artifact under a new scope; every ranged request uses existing scope verification and expiration signaling.
- Descriptor presentation: missing/null/empty optional values, zero size, nested metadata, direct Resources, exact source and ordered JSON Pointer associations must survive without invented names/references.
- Browser inert rendering: hostile YAML/schema/descriptor strings are ordinary diagnostic text. No HTML execution, URL navigation, resource resolution or prompt parsing.
- Java/Go fixtures: regeneration must preserve semantic expectations, exact-version checks, existing snapshots and LF files.
- Application API is unchanged and protected by the allowlist test. No supported SPI exists. Manifest/configuration contracts and canonical annotations remain unchanged. Traces are current-version diagnostics with existing exact-version portability, not a historical compatibility promise. React parser/state are internal and may change atomically without shims.
