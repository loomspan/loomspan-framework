## Contract scope and risks

Catalog REST and its Go/MCP/browser consumers form the coordinated serialized product boundary. Canonical traces and their derived manifests are current diagnostic formats, including the same-product-version complete-trace transfer. The closed Java Application API test protects the supported surface. Internal record signatures and fixtures are replaced atomically under the developer's breaking-change authorization.

The principal risks are a tuple that disagrees with its qualified key, namespace collision in detail navigation, old consumed capture grammar rejecting valid traces, canonical/provider spelling being confused, lost ordinary content during fixture conversion, and generated snapshots/checksums that cease to match their authoritative producer. Existing scope, authorization, retention, cursor and exact-version behavior are part of the regression gate.

The product marker remains `1.0.0-beta.10-SNAPSHOT` for the coordinated unreleased snapshot. Retain tests that reject missing or unequal resolved release strings and run normal complete validation for `development`. Catalog fields are required at the completed boundary. Tests should expect the complete current tuple and exact grammar.

**Type** — Go unit.

**Location** — `loomspan-console/internal/skillidentity/identity_test.go`.

**Proves** — Go consumed contract validation matches the Framework's exact grammar and captured-owner semantics.

Use table cases for `lookup`, `lookup-3pl`, `order-support`, lowercase digits after initial letters and valid 64-character standalone namespaces. Reject empty, uppercase, underscore, leading/trailing/repeated hyphens, first digits, whitespace, Unicode and either reserved substring. Test full-string matching, including a trailing newline.

For namespace `order-support`, a valid 49-character local name passes, and a 50-character one fails. Qualified input has exactly one colon and valid nonempty components. A provider double-hyphen name, bare local name and old combined key cannot pass as a qualified capture. An actual hyphenated local name such as `orders:warehouse-lookup` passes.

Use pure tables and maps. These are internal validation and current serialized/diagnostic contract checks.
