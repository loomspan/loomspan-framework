## Risk assessment

The greatest risk is silently changing a pre-existing target because an old foreign reference is now a valid local name. The conversion must trace each field to its declaration using `c271b80` and the PR 37.1 changes. Whole-file replacements cannot establish that target. New local hyphens introduced in PR 37.1 retain their local meaning.

Other risks are accidentally using the callable index for an executor or the reverse, letting a foreign registration satisfy a missing local dependency, bypassing Private/role/direct-call checks, and rewriting source data while preparing identities. Binding tests must retain exact source/task/mission matching, schema checks and isolation. Evidence tests must retain original columns after the reference spelling changes.

The compatibility analysis follows the implementation plan. Manifest behavior is an intentional replacement. Existing application-facing publication signatures and access boundaries retain their documented responsibilities. The repository exposes no supported SPI. Internal string constructors and canonical metadata keys are updated directly. Diagnostic source labels, paths, raw content and runtime fidelity remain protected. Console schema and provider/root entry changes have explicit later ticket ownership.
