## Desired End State

- Only MODEL and EXECUTOR YAML forms, and public `SkillKind.YAML`/`JAVA`, remain.
- Native top-level `typesafe` declarations fail ordinary unknown-field validation, including null/empty declarations and combinations with executor/model fields. Native `driver: typesafe` fails configuration enum validation; no translation or fallback occurs. Arbitrary `config.typesafe` domain keys remain valid.
- Provider runtimes hold only an ordinary ChatModel and generic retry/failure ownership. Generic cleanup, failed-construction cleanup, suppressed failures, generation retention and idempotent destruction remain intact.
- Current Java, Go, TypeScript, MCP schemas and fixtures agree on the two kinds. Native evaluation renderer assumptions and native-only corpus cases are gone.
- Generic runtime/authorization/binding/lifetime coverage survives using ordinary executors or chat providers.
- Current consumer docs describe executable pack syntax, complete response paths and accepted limitations without native setup recipes or historical migration narrative.
- All required local suites pass; execution notes identify the resulting local Framework coordinates, source commit/build identity and repeatable commands. Commit ticket-owned changes, without push/sync/publication.
