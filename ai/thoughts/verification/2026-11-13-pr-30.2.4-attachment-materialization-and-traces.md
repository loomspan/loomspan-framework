## Implemented behavior

- Shared declaration loading parses each attachment MIME with the media-construction parser and reports an offending entry/index without rewriting authored declarations.
- Actual canonical schema nodes drive materializer/coordinator traversal. Named properties precede typed-map schemas; arrays retain positions. Shared JSON Pointer escaping distinguishes literal punctuation, empty names and nested paths.
- The existing nonconsuming validator checks original references and all surrounding assertions before reads. Materialization validates real descriptors against a private generated schema copy. Canonical inputs, canonical schemas and provider trees remain unchanged; Resources are neither stringified nor serialized into that view.
- Immutable descriptor/rendered containers retain explicit nulls and absent filenames. Permitted nulls create no media; missing/required/null rules remain ordinary validation rules.
- Parsed MIME equality handles equivalent type/subtype case; signatures use normalized parsed type/subtype. Existing extension detection/single-MIME fallback and repeatability checks remain.
- The digest pass reads at most remaining byte budget plus one detection byte, computes actual size/SHA-256 and never invokes contentLength. Overflow checking precedes addition. Opening/mid-read failures preserve field pointer and original IOException cause. Existing image header pass remains separate and bounded to 16 bytes.
- Both engines record nonempty descriptor lists immediately after successful materialization. State service preserves writable-binding checks; recorder selects captured mission ID/route/type even if a model/planning frame is active. No descriptor record is emitted on failed materialization; later planning/model failures retain successful evidence.
- List and stream journal projections join metadata by exact frame ID using projection-local state; finished observer details use the existing mapper. The existing journal-only field-name rules are unchanged, canonical records are not mutated, and live activity receives no new collection.
- The generic standard-engine failure wrapper retains factual model/skill/media context and original cause without inferring incompatibility. Existing cancellation behavior is retained.
