# Evaluation rubric

A run passes only when its structured facts and direct limitations match the
case oracle, every reviewed criterion points to a quoted excerpt in the
unedited answer, all operations use installed tools, the scenario's minimum
multi-fixture or continuation traversal is present, complete headless visibility
is present, ambiguity is handled, and no unsupported causal, importance,
ownership, provenance, or client-action claim appears. Call order and prose are
not scored. Continuations, client externalization, raw reads, and unnecessary
calls remain observable efficiency facts rather than a memorized script.

An ambiguous recent-import run fails if it performs any trace-specific read
before clarification. Bounded semantic and raw traversal is scored only in the
separate case whose prompt supplies one exact `traceId`.
